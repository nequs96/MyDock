# MyDock

MyDock is an independent, local-first macOS Dock manager. It is being built from public Dockset documentation, using original code, original product branding, and native macOS frameworks.

## Development

Requirements: macOS 13 or later and Swift 6. Build the Swift package with:

```sh
swift build
```

Run the project test suite with:

```sh
./TestMyDock.sh
```

Create a universal local app bundle for Apple Silicon and Intel with:

```sh
./BuildMyDock.sh
open build/MyDock.app
```

The current workspace has Swift Command Line Tools but no full Xcode installation. `xcodebuild` is unavailable here; the Swift package build and local app bundle script are the verified build path. A generated [Xcode project](docs/XCODE_BUILD.md) is also included for an Xcode app build and Focus filter metadata verification. The local bundle targets macOS 13.0, contains arm64 and x86_64 slices, and includes an original icon generated by `Tools/GenerateAppIcon.swift`. `TestMyDock.sh` uses the Swift Testing framework shipped with the active developer tools.

## Current state

MyDock has a replayable four-step first-run flow, menu-bar profile switching, persistent native and Custom Dock profiles, a staged editor, app/file/folder/link/spacer items, a Custom Dock panel, backups, and transactional native Dock changes. Native profile applies snapshot, verify, roll back on error, and serialize with other Dock preference operations. Custom-main mode journals and restores Apple's prior auto-hide setting. Desktop-widget placement keeps the Custom Dock behind application windows. The Focus Filter intent selects saved native or Custom profiles and leaves the applied profile selected when Focus turns off; system discovery and invocation still need a full Xcode build and desktop acceptance. Automated Dock tests use fake preferences and never modify this Mac's real Dock.

The registry contains the 26 requested widget families plus the separately requested Trash tile. Local widgets include Clock, searchable multi-city World Clock, Stopwatch, Countdown, Alarm, Time Progress, Focus Timer, Sticky Note, Hydration, Battery, App Folder, System Activity, Network Activity, AirDrop, Trash, Shortcuts, Calendar, Reminders, Now Playing, Weather, Stock, Watchlist, Stripe, Paddle, Shopify, AI Limits, and AI Activity. Calendar and Reminders use EventKit when their popouts open. Weather uses Open-Meteo city search and forecast data, with optional current-location lookup. Market data uses Alpha Vantage end-of-day series. Stripe, Paddle, and Shopify use read-only provider APIs and per-account credentials in Keychain. AI Limits reads Codex's local read-only app-server quota response and Claude Code's documented status-line snapshot when configured; providers without a supported quota reader show unavailable. AI Activity reads local Codex and Claude Code counters and labels Grok session summaries as estimates. It does not retain prompt/tool text or send session records to a service. Business and market credentials are excluded from profile backups.

The Custom Dock can show and pin running apps, list and restore minimized windows, minimize the focused app on click, magnify hovered items, browse folders and customize folder tiles with local color/letter/number icons, scroll overflow with conditional jump chevrons, keep multiple widget/folder popouts in anchored tabs with ⌘W/Escape close, resize with a drag grip or size slider, choose Frosted/Dark/Liquid Glass materials (Liquid Glass on macOS 26+), auto-hide to a reveal handle with a 350 ms edge dwell, optionally hide when the visible Apple Dock overlaps, switch profiles through global shortcuts, and use perpendicular trackpad swipes to cycle profiles. Window controls need Accessibility permission. The manager supports multi-selection, Shift-click ranges, group movement/deletion, and staged Save/Discard edits. The Permissions tab reports current status and links to System Settings.

Important differences remain from Dockset: opt-in minimized-window previews use a session-only ScreenCaptureKit cache with app-icon fallback, but live permission and thumbnail behavior still need acceptance; app badge counts remain unavailable through public APIs. Optional ScreenCaptureKit desktop freeze for native Dock switching on macOS 14+ awaits permission and visual acceptance. Fullscreen-space participation, edge dwell, and Apple Dock overlap behavior need desktop verification. A DEBUG preview has been visually checked across all onboarding steps, the Manager, Settings, widget library, bottom/left/right Dock layouts, light/dark appearance, overflow navigation, and Clock popouts; this does not verify real Dock operations or the remaining OS interactions. Several provider quotas (Claude, Grok, Cursor, Gemini CLI, Copilot, Antigravity) and Cursor activity do not have supported readers. Live integrations need the user's provider accounts.
