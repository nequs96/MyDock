# MyDock

MyDock is an independent, local-first macOS Dock manager. It is being built from public Dockset documentation, using original code, original product branding, and native macOS frameworks.

## Development

The source of truth is `Sources/MyDock/`. The single canonical local app is **`build/MyDock.app`**, built from that source. It includes the premium redesign, bug audit, disappearing-Dock repairs, replacement mode and the direct-manipulation Dock workspace. Continue all future development from this working tree.

Requirements: macOS 13 or later, Swift 6 and the macOS 26 SDK. For the canonical app, quit MyDock first, then run:

```sh
./BuildMyDock.sh
open build/MyDock.app
```

Run the project test suite with:

```sh
./TestMyDock.sh
```

Rebuild and launch the same path after changes. The script refuses to overwrite a running bundle. Keep `build/` for this one app; temporary validation bundles belong under `.build/`. Swift package/debug and test products are development intermediates. The default VS Code build task uses the same app build script; existing Swift debugger configurations remain available.

The current workspace has Swift Command Line Tools but no full Xcode installation. `xcodebuild` is unavailable here; the Swift package build and local app bundle script are the verified build path. A generated [Xcode project](docs/XCODE_BUILD.md) is also included for an Xcode app build and Focus filter metadata verification. The local bundle targets macOS 13.0, contains arm64 and x86_64 slices, and includes an original icon generated by `Tools/GenerateAppIcon.swift`. `TestMyDock.sh` uses the Swift Testing framework shipped with the active developer tools.

MyDock has a replayable four-step first-run flow, menu-bar profile switching, persistent native and Custom Dock profiles, a direct Dock editor with merge-safe autosave and Undo, app/file/folder/link/spacer items, a Custom Dock panel, backups, and transactional native Dock changes. Native profile applies snapshot, verify, roll back on error, and serialize with other Dock preference operations. Replace macOS Dock mode suppresses ordinary edge-hover reveal and attention bouncing while MyDock runs. It journals and restores the previous auto-hide, reveal-delay and bouncing preferences when leaving the mode or quitting. Desktop-widget placement keeps the Custom Dock behind application windows. The Focus Filter intent selects saved native or Custom profiles and leaves the applied profile selected when Focus turns off; system discovery and invocation still need a full Xcode build and desktop acceptance. Default automated Dock tests use fake preferences. A separate live apply/restore test is disabled unless explicitly enabled in a disposable macOS environment.

The registry contains 35 widget families (registry-derived tests check provider and layout coverage; native acceptance is tracked in the execution ledger), including Disk Space, Calculator and Quick Checklist. Widgets offer independent per-item Layout and Icon settings. Horizontal layouts adapt their widths to the information: AI Activity has Compact, Standard and Activity; CPU has Compact, Meter and Trend; other families expose appropriate variants. Accent, Soft, Mono and Outline affect only the icon. Settings show an actual Dock-sized preview and dimensionally accurate layout choices. Older saved styles and widths migrate safely. Local widgets include Clock, searchable multi-city World Clock, Stopwatch, Countdown, Alarm, Time Progress, Focus Timer, Sticky Note, Hydration, Battery, App Folder, System Activity, Network Activity, AirDrop, Trash, Shortcuts, Calendar, Reminders, Now Playing, Weather, Stock, Watchlist, Stripe, Paddle, Shopify, AI Limits, and AI Activity. Calendar and Reminders use EventKit when their popouts open. Weather uses Open-Meteo city search and forecast data, with optional current-location lookup. Market data uses Alpha Vantage end-of-day series. Stripe, Paddle, and Shopify use read-only provider APIs and per-account credentials in Keychain. AI Limits reads Codex's local read-only app-server quota response and Claude Code's documented status-line snapshot when configured; providers without a supported quota reader show unavailable. AI Activity reads local Codex and Claude Code counters and labels Grok session summaries as estimates. It does not retain prompt/tool text or send session records to a service. Business and market credentials are excluded from profile backups.

The Custom Dock can show and pin running apps, list and restore minimized windows, minimize the focused app on click, magnify hovered items, open folders in Finder with a click or browse contents with a long press, and customize folder names, optional labels, and color/letter/number icons without renaming the Finder folder. It can scroll overflow with conditional jump chevrons, reorder saved tiles by dragging, and open an Add menu from the Dock surface. It can keep multiple widget/folder popouts in anchored tabs with ⌘W/Escape close, resize with a drag grip or Appearance controls, choose Compact/Balanced/Comfortable density presets with size and spacing fine-tuning, choose Frosted/Dark or Liquid Glass Regular/Clear (macOS 26+), and hide to a reveal handle with a 350 ms edge dwell. A saved option hides widget labels to make information cards narrower; each named bottom-Dock widget card can also use Compact, Standard, or Wide width from its context menu. Profile switching supports global shortcuts, perpendicular trackpad swipes, and Command+scroll. Global shortcuts for saved profiles are editable from Settings → Shortcuts or the Manager profile menu; Settings remembers the last page, and Dock context menus open the Dock page. Window controls need Accessibility permission. The manager supports multi-selection, Shift-click ranges, group movement/deletion, native Undo, direct canvas dragging, and merge-safe autosave. The Permissions tab reports current status and links to System Settings.

Settings → General can export a redacted diagnostic report with aggregate counts, save status, appearance choices, and recent fixed event codes. It excludes profile content, notes, paths, credentials, and window images; profile backups can include saved notes and widget snapshots, or export a sanitized layout only.

Important differences remain from Dockset. Opt-in minimized-window previews use a bounded local ScreenCaptureKit cache with app-icon fallback, but live permission and thumbnail behavior still need acceptance. Optional app badge labels use a bounded, best-effort Accessibility reader for Dock application items on macOS 14+; live label availability varies by app and still needs desktop acceptance. Optional ScreenCaptureKit desktop freeze for native Dock switching on macOS 14+ awaits permission and visual acceptance. Fullscreen-space participation, edge dwell, and Apple Dock overlap behavior need desktop verification. Earlier DEBUG-preview checks covered onboarding, the Manager, Settings, widget library, Dock positions, light/dark appearance, overflow navigation, and Clock popouts; the current implementation has a disposable visual and interaction pass, while production OS acceptance remains partial. No captures establish 1:1 parity with Dockset. Grok, Cursor, Gemini CLI, and Antigravity quotas plus Cursor activity do not have supported readers in this build. GitHub Copilot personal billing usage has an opt-in reader that needs a fine-grained token and manually entered monthly allowance; organization-billed usage is not included. Claude Code can provide documented status-line quota snapshots. Live integrations need the user's provider accounts. ### Unified workspace

Manage Docks and Settings open the same MyDock window. The sidebar navigates Docks, Explore, and Settings. Select and drag items in the Dock itself; **Add Item** opens the searchable app/widget library, and **⌘K** opens common commands. Contextual inspectors replace the permanent item grid and toolbar. Changes autosave, with failed drafts retained for retry. **Explore** offers Everyday, Deep focus, Creative space, Build & code, Commerce, Home office, Travel, AI workspace, and System monitor. Installed apps are resolved once, with missing-app fallback notes. Preview, rename, substitute/remove/add apps, then create the complete profile with one save. Cancel leaves the library unchanged. Personal presets can be saved, previewed, imported and exported with runtime snapshots and connection assignments removed.

In **Settings → Appearance**, choose Minimal (solid), Soft Frost, Liquid Glass, or Midnight, choose a global default or a specific profile, then adjust theme, color, tint, Dock scale, spacing and corners. Configure each widget’s layout and icon independently through Customize. Profiles inherit by default; overrides and the last appearance change can be undone. Liquid Glass requires macOS 26; earlier systems use frosted material. Replacement mode positions the custom Dock against the display edge while retaining the menu-bar safe area.

Settings → Integrations contains a Connections center for testing, replacing, disconnecting and remapping business accounts. General contains bounded local profile history, layout-only backup choices, Launch at Login, and manual update discovery from a publisher-owned GitHub repository. No release repository is configured by default. [ReleaseMyDock.sh](ReleaseMyDock.sh) prepares a full-Xcode, Developer ID signed and notarized distribution when the publisher supplies the required toolchain and signing identity. Local builds remain ad-hoc signed.
