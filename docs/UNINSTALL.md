# Removing MyDock

1. Open MyDock and save pending edits. If a save fails, use **Retry Save** and keep the app and its data until the failure is resolved. Export a backup from Settings if you want a portable copy; backups always exclude credentials, permissions and cached provider readings; the **Include personal widget data** option controls whether notes, checklists, snippets and similar personal content are included, so keep that file private.
2. In Settings → General, turn off **Launch at login**. Check the status text, then check MyDock in System Settings → General → Login Items if macOS reports an approval or missing-service problem.
3. If you want to remove stored credentials, use Settings → Integrations → Connections → **Disconnect and Remove Credentials** for each account, then Settings → Integrations → Market data → **Remove Key** and GitHub Copilot usage → **Remove Credentials**. This disconnects affected widgets; it does not revoke provider access. Revoke access separately at the provider if desired. Removing MyDock does not sign you out of Codex, Claude or other independently installed tools.
4. Quit MyDock normally from its menu or with Command-Q. Normal quit saves pending work and restores Apple Dock visibility preferences that MyDock owns. If restoration fails, MyDock keeps the recovery record and cancels quitting: resolve the reported issue and retry. If Settings shows **macOS Dock recovery required**, use **Restore Previous Dock** before removing the app.
5. After MyDock has exited, move the installed app to Trash. For a checkout build, the canonical app is `build/MyDock.app`. Do not move or overwrite a running app bundle.

Applying a saved macOS layout changes pinned content separately from visibility preferences. Quitting does not undo a successfully applied arrangement. Before removal, apply your desired saved native layout or arrange Apple's Dock yourself. Recovery restores an interrupted transaction, rather than reversing every past Apply.

App removal deliberately leaves personal data in `~/Library/Application Support/MyDock` and app preferences in the `app.mydock.MyDock` defaults domain. Profiles, private content, drafts, history, cache and recovery records can remain useful when reinstalling. Credentials stored in Keychain also remain unless removed in step 3. Do not remove recovery records while restoration is pending.

For an optional full data removal, first complete the steps above and verify restoration and exit. Keep a backup if needed, then remove the MyDock Application Support folder and its app preferences yourself. This permanently removes local authored content and recovery drafts; there is no automatic uninstall cleanup. Use the in-app connection controls before removal for credentials. Do not delete other tools' account files, credentials or configuration folders.

Signed installation, login-item removal and native restoration still require acceptance on a disposable macOS user. This guide documents the implemented paths; it is not evidence that those native scenarios passed.
