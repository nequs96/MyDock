## Source and data review

- No product `TODO`, `FIXME`, `TEMP`, `HACK`, `MOCK`, `STUB`, or `fatalError` markers remain. The two forced Accessibility bridges follow explicit Core Foundation type-ID checks. Tests contain fixed HTTP URL examples.
- Provider keys and access tokens are stored in Keychain and excluded from profile backups. The new diagnostic event stream writes only fixed codes; remaining operational logs report Dock recovery, persistence, or shortcut registration errors without passing credential values. The Now Playing UI no longer repeats raw AppleScript error text.
- Backup input has a 25 MiB cap enforced while the selected regular file is read, before JSON decoding; a focused regression checks exact-limit and over-limit behavior. Profile and item caps, URL policy checks, normalized bounded favicon data, and local-file validation for App Folder members also apply. Import reports missing top-level and nested paths and does not activate imported profiles.
- Storage scans skip hidden files, package descendants, and symlinks; they run in a detached task after a user action, support cancellation, disclose skipped/capped results, and never delete files. Home and Library totals are separate because the locations overlap.
- Site icons are fetched only on an explicit action with bounded HTTPS requests. Spotify artwork uses a bounded credential-free HTTPS request to `i.scdn.co` and stays in memory. Opt-in window previews are stored locally in a private, size-capped macOS Caches directory for up to 24 hours, keyed by hashed app/title identity, excluded from backups, and cleared when disabled or Screen Recording access is revoked.
- The Custom Dock's system, network, window, and Now Playing monitors stop or pause their recurring work while the Dock is hidden. Idle/active CPU and long-running memory measurements have not been completed; multi-display verification also remains outstanding.
- Native Dock auto-save stays off by default. When enabled, it reads pinned apps and spacers every five seconds, observes an initial baseline, ignores MyDock's own successful applies, and saves external changes only to the selected profile. Unsupported Dock tiles pause automatic saving instead of being silently dropped. Its fixture test never touches the real Dock.
- The optional menu-bar profile title is stored in settings, displays the applicable native and/or Custom profile names for each setup mode, truncates long names, and retains full names in the tooltip. Model and migration tests pass; live menu-bar title layout remains unchecked.
- The Custom Dock now offers a right-click Switch Profile submenu on its surface, regular tiles, and minimized-window tiles. Custom selections activate locally; native selections use the same transactional Dock controller as the menu bar. The menu compiles, but pointer behavior and native switching require unlocked desktop acceptance.
- AI Limits refreshes each visible provider through an independent adapter. Codex reads its local app-server; Claude Code can share documented subscription windows through an explicitly configured status line, which writes only percentages and reset times to a bounded local snapshot. Personal GitHub Copilot consumption uses GitHub's documented billing API when the user supplies a Plan: read token and monthly allowance; organization-billed usage and entitlement detection are not supported. MyDock does not read Claude credentials or query a private OAuth endpoint. Stale Claude samples expire after 30 minutes. Fixtures verify adapter failure isolation, cancellation, request construction, billing filtering, local file validation, freshness, reset times, and window parsing. Grok, Cursor, Gemini CLI, and Antigravity quotas remain unavailable. Official docs explain the remaining gaps: [Gemini CLI reports quota in `/stats model`](https://geminicli.com/docs/get-started/) and [prohibits third-party access through its OAuth backend](https://github.com/google-gemini/gemini-cli/blob/main/docs/resources/faq.md); [Cursor's API is for team administration](https://docs.cursor.com/en/account/teams/admin-api); [xAI's API limits](https://docs.x.ai/developers/rate-limits) are separate from [Grok subscription usage](https://docs.x.ai/grok/faq/). Claude setup is documented in [CLAUDE_CODE_LIMITS.md](../CLAUDE_CODE_LIMITS.md), against Anthropic's [official status-line schema](https://code.claude.com/docs/en/statusline). Live provider accounts remain unverified.
- Codex's limit parser accepts fractional percentages, rounds them for the integer display, and rejects booleans as percentages. The updated fixture passes.
- Claude Code's status-line fields are parsed from a reduced local snapshot. Missing percentages and stale samples remain unavailable rather than displaying old or fabricated values.
- Calendar and Reminders now refresh on EventKit changes, app activation, wake, and a five-minute cadence. Compact and popout views reject old selections and clear content when access is lost. EventKit access is checked again before snapshots are returned; a nil Reminders fetch reports a read failure rather than a zero count. The Calendar popout's date updates while open; Reminders Add captures the target list, preserves text typed during a slow save, blocks duplicate submissions, and shows mutation errors without hiding fetched reminders. Reapplying an unchanged widget configuration no longer writes the whole profile. These paths compiled and passed the current suite, but mutation races, permission revocation, and live external edits were not exercised on the locked desktop.
- Settings → Dock → Custom Dock appearance groups size and spacing with Compact/Balanced/Comfortable presets; changing a slider shows Custom, and Restore appearance defaults resets the complete appearance set. An unchanged settings update no longer publishes state or writes the full profile. Preset geometry and readability still need visual acceptance.
- Stripe, Paddle, and Shopify Connect re-check that the originating widget still exists and remains disconnected after network validation, before saving any Keychain credential. Shopify refresh checks current profile state before writing a refreshed credential. These guards compiled and passed the suite; delayed-network and live-account acceptance remain open.
- Disconnecting a shared Stripe, Paddle, or Shopify account now clears its reference and cached snapshot from all saved widgets, including other profiles, after the credential is removed. The confirmation warns that all widgets using it will disconnect. A reload regression proves the multi-profile state change persists while unrelated accounts remain selected.
- Weather search and location completions now reject superseded requests and removed widgets; changing search text clears old results, and current-location progress is distinct from forecast loading. Compact and popout forecasts re-read the saved widget before applying a response. These paths compile and pass the current suite; delayed responses and live Location permission behavior remain unverified.
- Stock and Watchlist searches now remove results as the query changes and reject old successes/errors. Stock invalidates a cached quote if the ticker's currency changes; both widgets check the current selection and currency before accepting a delayed quote. The changes compile and pass the suite, while live market and delayed-network UI acceptance remain open.
