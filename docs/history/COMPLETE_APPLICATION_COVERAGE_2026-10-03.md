# MyDock — complete feature and acceptance coverage, 2026-10-03

Companion to [the full A–I audit](COMPLETE_APPLICATION_AUDIT_2026-10-03.md). This matrix covers the current **35-family source registry** and all significant user-facing application/Dock workflows. Recommendations are unimplemented. It records the whole path from entry/action to service, saved state and feedback; relaunch gaps are explicit.

**Evidence:** S current source, T current automated tests, R isolated current native DEBUG preview or isolated source-slice execution (specified), V static sample render, H historical, U unverified. No V/T-only widget is marked fully Verified. “Defective” identifies a supported defect within a broader implemented feature; it does not mean every action fails. “Partially implemented” indicates missing lifecycle/interaction completion. “Blocked by environment or tooling” is used for Xcode/release execution, not every scenario deferred for user-state safety.

**Runtime scope:** canonical `build/MyDock.app` inspected/hash checked, not launched/replaced; disposable universal Release built, not desktop accepted. Native workspace actions used isolated preview bundles and temporary state. Permission grants/accounts/clipboard/native preferences/transfers/destructive actions were not performed. All widgets share semantic layout/icon configuration; T WP/PR is registry/model/symbol coverage, not live face, VoiceOver or native integration acceptance. Layout heights are 54 base points with family-specific widths; side mode uses compact faces. All families need actual bottom/side/min/max/large-value and focus acceptance unless explicitly observed.

Test abbreviations below link to the actual file. `PS:535`, for example, points to a verified current test declaration line, not a count of tests. R means only the scenario described; close/reopen in-process is different from relaunch. Named missing-state behaviors in the table are S unless explicitly R/T/V.

## Acceptance interpretation

The matrix does not count source presence as acceptance. Saved utility collections have real store-recreation tests; the isolated native snippet workflow exercised Save and pending-input loss. Actual Clipboard/share/file-promise/color sampling is U. Provider transport/parser fixtures establish request and aggregation contracts without account authentication acceptance. Notification generation tests are not OS delivery tests. Native Dock preference rollback tests use injected backends; real mutation opt-in was deliberately not run. Geometry and offscreen corner pixels are not smoothness or wallpaper compositing evidence.

The full report provides stable defect IDs, priorities, component/regression/migration risks, current artifact paths and precise remaining procedures H1–H9. Every registered family is included here even where the adaptive export omitted it; no historical widget count was used as current inventory.
