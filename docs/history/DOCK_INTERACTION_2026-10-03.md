# Dock interaction and settings follow-up

Recorded 3 October 2026, Europe/Warsaw. Source of truth remains `Sources/MyDock/`. Canonical app path remains `build/MyDock.app`.

## Implementation

- Running pinned and transient app icons expose normal **Quit App** in their context menu. The selected installed copy is matched by its resolved bundle path; the action rechecks PID and bundle identity. There is no force-quit path. Minimized-window tiles expose **Close Window** and **Quit App**; app menus also expose a Close Window submenu for known windows. Closing reuses the uniquely identified AX window resolution used by Restore, then presses its native Close button off the main actor with bounded AX messaging. App save dialogs are retained. Close Window requires existing Accessibility access.
- Direct drag resizing publishes a transient, profile-scoped preview rather than modifying persistent state on every pointer event. Only the panel frame is refreshed during the drag, at most once per 8ms; its hosting root and live monitoring remain intact. The final size is persisted once on release, with existing global/profile inheritance and one history snapshot. SwiftUI layout animations are suppressed during resizing. App and window icon source images are cached independently of fractional display size.
- **Glass opacity** provides a continuous 0–100% neutral backing from transparent to opaque, independent of Clear/Frosted finish and profile tint. It updates the actual shared Dock surface and editor preview. Global settings bound imported values; older profile snapshots decode the missing optional field as zero, preserving the previous native glass appearance. Profile validation rejects nonfinite/out-of-range opacity.
- The small top-right Settings category picker is replaced by visible named section buttons with familiar symbols and a subdued selected state. The bar wraps at narrow widths to keep every section reachable without a hidden horizontal menu. Standalone Settings retains its full sidebar.
- Behavior → **Dock animations** offers an on/off switch, **Fade**, **Slide**, **Gentle grow**, and **Preview animation**. Reduce Motion suppresses effects. Grow animates the composited layer, keeping the window viewport constant so overflow controls and tiles do not reflow mid-animation. Slide uses the existing small edge offset. Preview notifications are scoped to the owning ProfileStore, keeping isolated validation separate from the user's Dock.
