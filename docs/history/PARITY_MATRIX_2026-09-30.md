# MyDock parity matrix (dated, 30 September 2026)

Moved from `docs/PARITY_MATRIX.md` on 7 October 2026. It repeated the per-feature status that [the feature matrix](../reference/FEATURE_MATRIX.md) carries, so it is kept here as a dated record; statements such as "current" and "currently passing" describe the 30 September build. Status against the public Dockset v0.2.6 documentation, researched September 26, 2026. Feature-level details and narrower statuses are in [FEATURE_MATRIX.md](../reference/FEATURE_MATRIX.md). Automated status reflects the current test suite; manual UI and real-Dock acceptance are partial.

The Visual checked column means full desktop acceptance, which remains incomplete. A safe DEBUG preview was visually inspected for all onboarding steps, the Custom Dock in bottom/left/right layouts, Manager, Settings, widget library, light/dark appearance, overflow navigation, and Clock popouts; see [visual parity notes](VISUAL_PARITY_2026-09-30.md).

Current implementation (30 September 2026): the 190-test registered suite passes with opt-in performance and real-system checks explicitly gated. The roadmap now includes draft merge/exit safety, native recovery health, shared refresh, bounded external work, common runtime geometry, typed group/end drops, continuous motion, revision writes, real sample previews, profile appearance overrides, nine staged presets, Connections, repair/history, honest market ranges, search/accessibility controls, login/release discovery and distribution tooling. [IMPLEMENTATION_STATUS.md](../IMPLEMENTATION_STATUS.md) is the canonical ticket/evidence ledger. Manual preview checks establish selected interactions and visual layouts; a Partial row still reflects incomplete production desktop/provider/distribution acceptance.

## Automated coverage currently passing

- profile persistence/reload and active selection;
- spacer identity and order through JSON and item moves;
- backup add-only import, fresh identities, missing-path report, and unsafe-link rejection;
- native Dock serializer order and spacer kinds;
- fake native Dock apply, rollback after a preference write failure, and serialized rapid requests.
- Sticky Note/Focus Timer configuration persistence, backup round-trip, and elapsed-time calculation.
- corrupt profile recovery and protection from overwriting a future schema.
- hydration history, partial-volume labeling, and exact-entry undo.
- battery percentage parser handles absent data and clamps out-of-range readings.
- Calendar and Reminders widget configuration round-trips through backups; event ordering prioritizes ongoing/soon timed meetings over all-day entries.
- CPU percentage delta math, live uptime/memory/volume readings, storage scan file-size ordering/hidden-file exclusion/progress/cancellation, and hidden-Dock sampling policy.
- Alarm weekday/next-time calculations and backup round-trip; network rate calculation and counter rollover.
- Duplicating a profile preserves alarm definitions while disabling schedules tied to original widget IDs.
- Weather forecast payload parsing, city display names, and Weather configuration/cache backup round-trip.
- AirDrop link validation accepts HTTP(S) URLs and rejects unsafe or incomplete schemes.
- Trash item counting includes hidden and visible entries at the top level of a fixture directory.
- Now Playing response parsing and source/layout/seek-interval backup configuration.
- Alpha Vantage ticker/series parsing, provider-limit errors, safe ticker validation, and watchlist backup configuration.
- Localized Dock magnification policy, Reduce Motion handling, perpendicular trackpad profile-switch thresholds, and multi-city World Clock city search, date-offset math, and backup configuration.
- Native and Custom profile color persistence through backup; multiple-item removal persistence.
- Duration and absolute-date Countdown modes, target-date persistence, completion alert identity, and duplicate-profile behavior.
- Shift-click range selection policy and multi-item group movement preserving item order.
- Dock profile draft discard behavior and explicit save persistence.
- Per-core CPU delta math and live host processor/thermal/load snapshot.

Additional passing fixtures cover Shopify client-credentials authentication, GraphQL pagination/order caps, store-timezone periods, currency, returns/test/canceled order treatment and backup exclusion; AI Codex quota windows (including fractional percentages), Claude status-line quota windows and stale-sample handling, independent provider failure handling, Codex/Claude local activity counters, estimated Grok session summaries, DST ranges and content exclusion; Focus-off no-op behavior; and Custom-main Dock auto-hide recovery/rollback with fake preferences. These tests use temporary files or fake adapters. They do not alter the real Dock preferences, inspect production UI, or establish visual parity.
