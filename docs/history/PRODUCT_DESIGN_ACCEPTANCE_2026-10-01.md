## Current native acceptance

Native UI access resumed. Old previews were quit cleanly, the canonical app launched with five existing profiles/live widget contents preserved, and the updated isolated editing/keyboard checks above passed. That resumed pass restored ordinary click/keyboard observations; access became unavailable again after the latest successful canonical launch described below.

The user confirmed the same end-drop failure with a physical mouse. The unreliable SwiftUI drag delegates were replaced with one `DockCanvasDragView`: direct internal pointer tracking, snapshot lift, group-aware insertion, native URL destination and profile validation. Isolated native checks passed: Clock to end plus Undo; Clock/Weather to end/start without changing relative order; narrow spacer between widgets; outside release cancellation; right-click context menu. The final source retested end drop and new-item focus. Two native regressions cover event delivery/cancellation/profile switching and ordered pasteboard payloads/URLs. Default tests report 230 in 16 suites. Obsolete provider loader/delegates are removed.

The canonical bundle was rebuilt after a clean quit. Latest canonical native launch passed through MyDock > Manage Docks with all five existing profiles and live widget contents preserved; Command-K and Escape passed. The current 74-layout matrix includes the 18 accessibility variants below. CUA later again returned `cgWindowNotFound` for canonical and isolated windows. No running bundle was overwritten or forcibly terminated. External/empty/overflow pointer flows, post-drag keyboard/held-Escape/lift quality, real compact resizing and production motion still require acceptance.

## Follow-up accessibility refinement

The current-source isolated Custom Dock runtime opt-in passed after the accessibility changes: three edges, mode transitions through polling ticks, menu retention and resize retention, 18.380 seconds. It uses a disposable store and injected overview metadata, without modifying Apple's Dock. The previous pointer-source 18.527-second run is retained as dated evidence in `.build/product-rebuild-runtime.log`.

Fixed low-opacity editor outlines now use `DockDesign.Outline` and shared `DockAccessibilityStyle`. `DockMaterialSurface` owns one contrast-aware boundary shared by editor/live rendering; widget containers, controls, search fields and appearance presets follow the same tokens. Reduce Transparency uses opaque material. A DEBUG-only environment override and isolated high-contrast appearance render app-owned drawing without changing system accessibility preferences. The 74-layout matrix includes 18 dark/light contrast/opaque/combined workspace, actual Settings-shell and Dock variants. Their contact sheet and selected full-size screenshots were reviewed; light Midnight miniature icons were corrected to white. This establishes deterministic visual coverage, not actual global setting or VoiceOver acceptance.

## UI regression harness follow-up

The Xcode UI suite still targeted the removed Your Docks navigation and permanent Save/Discard controls. Those stale scenarios were replaced by word-boundary rename across autosave/Settings, Add Library selection/Delete/Undo, Command-K Settings/workspace transitions, profile creation/duplication and pointer end-drop/Undo. Tile queries are scoped to the editor window to avoid counting the separate inert Dock preview. Preview teardown now follows Command-Q with a normal-termination wait. Parser and whitespace checks pass; full-Xcode typechecking/selector validation/execution remains open. This changes test sources only; the canonical app/source fingerprints above are unchanged. Native CUA window access remains unavailable in this follow-up.
